# InkPress Studio — 1-Page Print Shop Demo

A mobile-first, responsive 1-page landing page template built for local print shops and small businesses.

**Live Demo:** [View Site](https://Zerefa02.github.io/inkpress-demo/)

## Features
- Mobile-first CSS Grid and Flexbox layout (tested down to 360px)
- Direct Messenger call-to-action links for fast ordering
- Transparent pricing cards, recent work gallery, and interactive FAQ accordion
- Lightweight vanilla HTML, CSS, and JS with zero external frameworks

## Built With
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
